# الربط الاختياري مع Claude Code وCodex عبر MCP (قراءة فقط)

> البرنامج يعمل كاملًا دون أي ذكاء اصطناعي. هذه الوحدة **غير مفعلة افتراضيًا**، ولا يغيّر البرنامج إعدادات أي أداة أو حساب تلقائيًا، ولا يفتح أي منفذ شبكة.

## كيف يعمل الربط

- يحتوي البرنامج المثبت على خادم MCP محلي صغير (`resources\app.asar.unpacked\dist\mcp\server.js`) يعمل عبر **stdio** فقط: الأداة (Claude Code أو Codex) هي التي تشغّله على الجهاز نفسه عند الحاجة، ويتواصلان عبر المدخلات والمخرجات القياسية دون شبكة.
- يُشغَّل الخادم بملف البرنامج نفسه في وضع Node (`ELECTRON_RUN_AS_NODE=1`)، فلا يلزم تثبيت Node.js.
- يفتح الخادم قاعدة بيانات المكتب **للقراءة فقط**، ويكتب سجل الوصول في ملف مستقل (`data\integration\access-log.sqlite`) يظهر في الإعدادات.
- في **كل استدعاء** يتحقق الخادم من: تفعيل التكامل في البرنامج، وصلاحية الرمز (غير ملغى وغير منتهٍ)، وأن القضية أو العميل المطلوب داخل نطاق الرمز. الإلغاء أو التعطيل يسري فورًا.

### الأدوات المتاحة (كلها قراءة فقط)

| الأداة | الوظيفة |
|---|---|
| `find_clients` | البحث عن عميل ضمن النطاق |
| `list_client_cases` | قضايا عميل مع المرحلة والحالة والموعد التالي |
| `find_cases` | البحث بالاسم أو رقم الملف أو الرقم الرسمي أو الخصم؛ يعيد **كل** المطابقات ولا يختار عشوائيًا |
| `get_case_summary` | ملخص منظم: رقم الملف والعميل والمرحلة وآخر الإجراءات وحالة المذكرات والجلسة القادمة والمهام والمراجع وتاريخ آخر تحديث |
| `list_case_schedule` | الجلسات والمهام والمواعيد الإجرائية لقضية |
| `list_upcoming` | الجلسات القادمة في القضايا المسموحة |
| `list_case_documents` | بيانات المستندات دون محتواها |
| `read_document_text` | نص مذكرة مكتوبة في البرنامج أو نص مستخرج محليًا من مستند — **فقط** إذا سمح الرمز بذلك |

لا توجد أدوات كتابة أو حذف أو SQL أو قراءة ملفات عشوائية أو أوامر نظام تشغيل.

**مثال:** عند سؤال «قضية أحمد ماذا حصل فيها؟» تستدعي الأداة `find_cases`. إن وُجدت أكثر من قضية يعيد الخادم كل المطابقات مع تنبيه بطلب التحديد، ثم يُستدعى `get_case_summary` للقضية المحددة. كل ملخص يتضمن تنبيهًا بأن غياب واقعة في السجل لا يعني عدم حدوثها.

## تنبيه الخصوصية (اقرأه قبل التفعيل)

عند استخدامك Claude Code أو Codex، **قد يُرسل النص الذي يقرأه الخادم إلى مزود الذكاء الاصطناعي** (Anthropic أو OpenAI) لمعالجته. هذه المعالجة **ليست محلية**. امنح كل رمز أضيق نطاق ممكن، ولا تسمح بقراءة نصوص المستندات إلا عند الحاجة.

قفل شاشة البرنامج لا يوقف الربط؛ الربط له مصادقة مستقلة (الرمز). لإيقافه: عطّل التكامل أو ألغِ الرمز.

## خطوات الإعداد

1. افتح البرنامج بحساب صاحب المكتب ← **الإعدادات ← الربط بأدوات الذكاء الاصطناعي**.
2. اقرأ التنبيه، وحدد خانة الإقرار، ثم **تفعيل وحدة التكامل**.
3. **إصدار رمز ربط**: اختر العملاء أو القضايا المسموحة، وحدد إن كنت تسمح بقراءة النصوص، ويمكنك تحديد تاريخ انتهاء.
4. يظهر الرمز **مرة واحدة** مع أوامر إعداد جاهزة فيها المسارات الصحيحة لجهازك. انسخ ما يناسب أداتك.

### Claude Code

بأمر واحد (نطاق المستخدم ليعمل في كل المشاريع؛ الخيارات قبل اسم الخادم، ثم `--` ثم الأمر):

```
claude mcp add --env ELECTRON_RUN_AS_NODE=1 --env LAWOFFICE_DATA_DIR="C:\Users\<المستخدم>\AppData\Roaming\LawOfficeManager\data" --env LAWOFFICE_MCP_TOKEN=lom_... --transport stdio --scope user law-office -- "C:\Users\<المستخدم>\AppData\Local\Programs\LawOfficeManager\LawOfficeManager.exe" "C:\Users\<المستخدم>\AppData\Local\Programs\LawOfficeManager\resources\app.asar.unpacked\dist\mcp\server.js"
```

أو ملف `.mcp.json` في جذر مشروع (يطلب Claude Code موافقتك قبل استخدامه):

```json
{
  "mcpServers": {
    "law-office": {
      "command": "C:\\Users\\<المستخدم>\\AppData\\Local\\Programs\\LawOfficeManager\\LawOfficeManager.exe",
      "args": ["C:\\Users\\<المستخدم>\\AppData\\Local\\Programs\\LawOfficeManager\\resources\\app.asar.unpacked\\dist\\mcp\\server.js"],
      "env": {
        "ELECTRON_RUN_AS_NODE": "1",
        "LAWOFFICE_DATA_DIR": "C:\\Users\\<المستخدم>\\AppData\\Roaming\\LawOfficeManager\\data",
        "LAWOFFICE_MCP_TOKEN": "lom_..."
      }
    }
  }
}
```

للتحقق: `claude mcp list` ثم `/mcp` داخل Claude Code. ملاحظة: ملف `.mcp.json` يحوي الرمز نصًا؛ لا تضعه في مستودع مشترك.

### Codex

في الملف `%USERPROFILE%\.codex\config.toml` (السلاسل بين علامتي `'` لا تحتاج مضاعفة الشرطة المائلة العكسية):

```toml
[mcp_servers.law_office]
command = 'C:\Users\<المستخدم>\AppData\Local\Programs\LawOfficeManager\LawOfficeManager.exe'
args = ['C:\Users\<المستخدم>\AppData\Local\Programs\LawOfficeManager\resources\app.asar.unpacked\dist\mcp\server.js']
startup_timeout_sec = 30

[mcp_servers.law_office.env]
ELECTRON_RUN_AS_NODE = "1"
LAWOFFICE_DATA_DIR = 'C:\Users\<المستخدم>\AppData\Roaming\LawOfficeManager\data'
LAWOFFICE_MCP_TOKEN = "lom_..."
```

أو بالأمر: `codex mcp add law_office --env ELECTRON_RUN_AS_NODE=1 --env LAWOFFICE_DATA_DIR="..." --env LAWOFFICE_MCP_TOKEN=lom_... -- "...\LawOfficeManager.exe" "...\server.js"`

## المتابعة والإيقاف

- **سجل وصول الربط** في صفحة الإعدادات نفسها: الوقت والرمز والأداة والنتيجة (مسموح / مرفوض).
- **إلغاء رمز**: زر «إلغاء» بجانبه — يتوقف فورًا.
- **تعطيل التكامل كله**: زر «تعطيل التكامل» — كل الاستدعاءات تُرفض فورًا.
- لا يعمل الربط في جلسة سحابية لا تستطيع الوصول إلى ملفات هذا الجهاز؛ يجب أن تعمل الأداة على الجهاز نفسه الذي يحمل البيانات.

## ما تم اختباره

- خادم MCP الفعلي عبر عميل MCP الرسمي: رفض الوصول قبل التفعيل، احترام النطاق، عدم وجود أدوات كتابة، اشتراط إذن قراءة النصوص، سريان الإلغاء والتعطيل فورًا، وعدم تغير قاعدة المكتب.
- التشغيل بملف البرنامج المغلف نفسه في وضع `ELECTRON_RUN_AS_NODE` (على لينكس، وعلى ويندوز ضمن اختبارات GitHub Actions).
- لم يُختبر الاتصال من Claude Code أو Codex على جهازك؛ صيغ الإعداد أعلاه مأخوذة من وثائقهما الرسمية (نوفمبر 2026):
  - Claude Code: https://code.claude.com/docs/en/mcp
  - Codex: https://developers.openai.com/codex/mcp
