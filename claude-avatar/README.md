# Claude Avatar — تحدّث مع Claude Code صوتيًا عبر شخصية ثلاثية الأبعاد على macOS

تتكلم بالعربية في ميكروفون الماك. يستقبل Claude Code الأمر وينفّذه على جهازك، مثل الملفات والأوامر والبرمجة والبحث، ثم يرد بصوت عربي تنطقه شخصية ثلاثية الأبعاد يتحرك فمها وعيناها ورأسها.

**العقل هو Claude Code نفسه** وبحسابك الحالي، والمحادثة كلها جلسة Claude Code واحدة تحتفظ بالسياق. لا يُستخدم ChatGPT ولا OpenAI ولا Claude API بمفتاح منفصل.

```
الميكروفون ─► كشف الكلام (في المتصفح) ─► whisper.cpp (محلي) ─► نص
   ─► claude -p --resume <جلستك>  (Claude Code ينفّذ الأدوات ويرد)
   ─► الرد يصل كلمة بكلمة ─► تقسيم لجمل ─► صوت عربي (say / Majed)
   ─► الشخصية VRM: تحريك الفم حسب الصوت + رمش + حركة عين ورأس وجسم
```

| المكوّن | الأداة | السعر |
|---|---|---|
| العقل والتنفيذ | Claude Code (الوضع غير التفاعلي الرسمي `-p` مع `--resume`) | ضمن اشتراكك الحالي |
| تحويل الكلام لنص | whisper.cpp + نموذج large-v3-turbo، ويعمل محليًا بدون إنترنت | مجاني ومفتوح المصدر |
| تحويل النص لصوت | صوت macOS العربي (Majed) عبر الأمر `say`، ويعمل محليًا | مجاني ومدمج |
| الشخصية | three.js + three-vrm، والمكتبات مضمّنة في المشروع | مجاني ومفتوح المصدر |

## التثبيت (مرة واحدة)

```bash
git clone -b claude/chatgpt-3d-avatar-macos-0iqury https://github.com/xiz55/home-11.git ~/claude-avatar-repo
```

```bash
cd ~/claude-avatar-repo/claude-avatar && ./install.sh
```

المثبّت يفحص الجهاز (إصدار macOS والمعالج والذاكرة وHomebrew وClaude Code وتسجيل الدخول)، **ويطلب موافقتك قبل أي تثبيت**:
- `brew install whisper-cpp`
- تنزيل نموذج Whisper (حوالي 550 MB)
- تنزيل الشخصية التجريبية
- اختصار على سطح المكتب

## التشغيل

انقر مرتين على **Claude Avatar.command**، أو شغّل الأمر التالي:

```bash
~/claude-avatar-repo/claude-avatar/Claude\ Avatar.command
```

1. تفتح نافذة مستقلة للشخصية، في Chrome أو Edge أو Brave بوضع التطبيق، وإلا في Safari.
2. اضغط **«ابدأ المحادثة»** واسمح باستخدام الميكروفون.
3. تكلّم بشكل طبيعي. حين تسكت قرابة ثانية يُرسل كلامك تلقائيًا.

| الإجراء | الطريقة |
|---|---|
| الاستماع التلقائي أو الضغط للتحدث | زر «🎙 الاستماع»، وفي وضع الضغط: اضغط مع الاستمرار على **مسافة** |
| مقاطعة الشخصية أثناء كلامها | تكلّم بصوت واضح فتسكت وتسمعك، أو اضغط **Esc** أو «⏹ إيقاف» (يوقف تنفيذ Claude أيضًا) |
| محادثة جديدة | زر «محادثة جديدة» |
| ملء الشاشة | زر ⛶، أو ⌃⌘F |
| تغيير الشخصية | زر «تغيير الشخصية» أو اسحب ملف `.vrm` إلى النافذة |
| الكتابة بدل الكلام | خانة النص أسفل النافذة |
| إيقاف المساعد كليًا | `stop.command` |

يظهر رقم جلسة Claude Code أسفل النافذة. يمكنك متابعة المحادثة نفسها في الطرفية بالأمر `claude --resume <الرقم>`.

## الإعدادات (`config.json`)

| المفتاح | الوصف |
|---|---|
| `workdir` | المجلد الذي يعمل فيه Claude Code (الافتراضي: مجلد المستخدم `~`) |
| `permission_mode` | `acceptEdits` (الافتراضي): تعديل الملفات مسموح، والأوامر الطرفية المسموحة فقط هي المذكورة في `allowed_tools`. `auto`: وضع Claude Code التلقائي إن كان متاحًا في اشتراكك، وفيه مصنّف أمان يوافق على الإجراءات أو يمنعها. `bypassPermissions`: يسمح بكل شيء، **ولا يُنصح به مع التحكم الصوتي** |
| `allowed_tools` | قائمة الأدوات والأوامر المسموحة بصيغة Claude Code، مثل `"Bash(brew:*)"`. انسخ القائمة الافتراضية من `server.py` وعدّلها |
| `model` | فارغ = النموذج الافتراضي في Claude Code، أو مثلًا `"sonnet"` أو `"haiku"` لردود أسرع |
| `language_style` | `saudi` (لهجة سعودية بيضاء) أو `msa` (فصحى مبسطة) |
| `tts.voice` | `auto` يختار أفضل صوت عربي مثبت، أو اسم صوت محدد مثل `"Majed (Enhanced)"` |
| `tts.rate` | سرعة الكلام (كلمة في الدقيقة) |
| `tts.engine` | `say` (الافتراضي) أو `edge`، انظر الملاحظة أدناه |

بعد تعديل الإعدادات: شغّل `stop.command` ثم أعد التشغيل.

**لصوت أوضح:** إعدادات النظام ← تسهيلات الاستخدام ← المحتوى المنطوق ← صوت النظام ← إدارة الأصوات ← العربية ← نزّل **Majed (Enhanced/Premium)**. المساعد يختاره تلقائيًا.

**صوت سعودي عصبي (اختياري):** `pipx install edge-tts` ثم `"tts": {"engine": "edge", "edge_voice": "ar-SA-HamedNeural"}`. الصوت أكثر طبيعية، لكنه يعتمد على خدمة Microsoft عبر الإنترنت بطريقة غير رسمية، وقد يتوقف دون إنذار. لهذا ليس الخيار الافتراضي.

## شخصية بشرية بمظهر احترافي

الشخصية التجريبية بأسلوب الأنمي. لشخصية بشرية:
- **VRoid Studio**: برنامج مجاني لـmacOS. صمّم شخصية بملابس رسمية وشعر وملامح كما تريد، ثم Export ← VRM.
- **VRoid Hub**: نماذج جاهزة. اختر نموذجًا يسمح ترخيصه بالتنزيل والاستخدام.

بعدها ضع الملف في `web/models/default.vrm`، أو اسحبه إلى النافذة. أي شخصية بصيغة VRM 0.x أو 1.0 تعمل، وتحرّك الفم يحتاج تعبيرات الفم القياسية (aa / ih / ou / ee / oh) الموجودة في نماذج VRoid.

## القيود (بصراحة)

- **الشخصية لا تفهم الكلام.** حركة الفم تعتمد على شدة الصوت وتوزيع تردداته، والرأس والعينان حركات طبيعية مبرمجة. الفهم والتنفيذ كله عند Claude Code.
- **لهجة الصوت:** Claude يكتب الرد بلهجة سعودية، لكن صوت macOS العربي ينطقه بنطق أقرب للفصحى.
- **مدة كل رد:** كل رسالة تُشغّل Claude Code بأمر مستقل يستأنف الجلسة نفسها، فيضيف ذلك ثانية إلى ثانيتين قبل بدء الرد. الصوت يبدأ مع أول جملة مكتملة ولا ينتظر نهاية الرد.
- **الصلاحيات:** في الوضع غير التفاعلي لا يستطيع Claude Code سؤالك عن صلاحية أثناء التنفيذ. الأداة غير المسموحة تُرفض، ويظهر ذلك أسفل النافذة ويخبرك Claude به. وسّع `allowed_tools` حسب حاجتك. وفي وضع `acceptEdits` قد يسمح Claude Code تلقائيًا ببعض أوامر الملفات داخل `workdir`، مثل الإنشاء والنسخ وربما الحذف، حسب إصداره. لذلك اجعل `workdir` مجلد عمل محددًا لا مجلدًا حساسًا. كذلك طُلب من Claude أن يستأذنك صوتيًا قبل أي إجراء خطير.
- **المقاطعة والصدى:** المتصفح يلغي الصدى، والمقاطعة تحتاج صوتًا أعلى من صوت الشخصية. مع سماعات الرأس تكون المقاطعة أدق، ولا يوجد صدى إطلاقًا.
- **وضع `/voice` الرسمي في Claude Code** إملاء صوتي بالضغط على زر في الطرفية فقط: لا ينطق الردود ولا يحرّك شخصية. لذلك بُني هذا الجسر، وهو يستخدم واجهة Claude Code الرسمية غير التفاعلية (`-p`، `--output-format stream-json`، `--resume`).

## حل المشكلات

| المشكلة | الحل |
|---|---|
| «تحويل الكلام غير جاهز» | شغّل `./install.sh`، ثم راجع `server.log` |
| لا يُطلب إذن الميكروفون أو لا يعمل | إعدادات النظام ← الخصوصية والأمان ← الميكروفون ← فعّل المتصفح المستخدم |
| يلتقط ضجيجًا كأنه كلام | استخدم وضع الضغط للتحدث (مسافة) |
| Claude لا يرد | شغّل `claude` في الطرفية وتأكد من تسجيل الدخول، ثم راجع `server.log` |
| فحص سريع | `python3 server.py --check` |
